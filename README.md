# RasPi3B-case
Slim 3d-printable enclosure for Raspberry Pi 3B

Features:
- As slim as possible
- Snap-fit construction, so no fastener hardware needed (although 3d-printed snap-fits like this are pretty much single use)
- Easy access to the ports and the microSD card reader
- Prints without supports
- Native CAD files (Creo Parametric 13.4.1.0) available
